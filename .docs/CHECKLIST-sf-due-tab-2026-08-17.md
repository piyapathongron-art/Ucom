## 5. ลบบิล

> 5.3 **ลบของจริงบน prod แบบย้อนไม่ได้** — บิล `100` เป็นข้อมูลทดสอบ (รุ่นชื่อ `test`)
> ถ้าไม่อยากให้หาย ให้ข้าม 5.3 แล้วติ๊กว่า "ข้าม"

| # | ทำ | ผลที่ต้องได้ | ผ่าน? |

## 6. ช่องโหว่ที่อุดไปแล้ว — ยืนยันว่าปิดจริง

เปิด DevTools → Console บนหน้าไหนก็ได้หลังล็อกอิน **Staff** แล้ววาง:

```js
const r = await fetch(
  `${process.env.NEXT_PUBLIC_SUPABASE_URL ?? location.origin}/rest/v1/v_sf_order_devices?id=eq.00000000-0000-0000-0000-000000000000`,
  { method: "PATCH", headers: { "Content-Type": "application/json" }, body: '{"list_price":1}' }
);
console.log(r.status);
```

| # | ผลที่ต้องได้ | ผ่าน? |
|---|---|---|
| 6.1 | status ต้องเป็น **401 หรือ 403** (ไม่ใช่ 2xx) — เขียนผ่าน view ไม่ได้ | ☐ |

> ถ้าขี้เกียจทำข้อ 6 ก็ได้ — ตรวจระดับ SQL ไปแล้วว่า `authenticated` เหลือแค่ `SELECT, TRIGGER`
