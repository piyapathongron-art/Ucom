# วิธีใช้ฝากเงินผ่าน LINE

สถานะ: ทดสอบในเครื่องและผ่าน scrutinize แล้ว ฐานข้อมูลติดตั้งแล้ว กำลังเผยแพร่แอป ระบบเงินสดยังไม่เปิดใช้ ต้องตรวจสลิป/LINE จริงและนับเงินตั้งต้นก่อน

## พนักงานนำเงินไปฝาก

1. พิมพ์ `/ฝากเงิน` ในกลุ่มร้าน แล้วกดปุ่มเปิดฟอร์ม หาก LINE ยังไม่ได้เข้าสู่ระบบ ให้ใช้บัญชี POS ของร้าน
2. ให้ POS หลักจัดการบิลค้างให้ครบแล้วกดหยุดรับเงิน จากนั้นรีเฟรชฟอร์มมือถือ
3. เลือกวันหรือยอดตั้งต้นที่ยังรอฝาก ระบบแสดงยอดแต่ละวันและรวมให้ วันที่ถูกนำเงินออกไปแล้วจะเลือกซ้ำไม่ได้
4. ใส่ “เศษเข้าเก๊ะก่อนออกจากร้าน” และแยกเงินจริงเข้าเก๊ะก่อน เช่น เลือก 16,457 บาท เข้าเก๊ะ 57 บาท จึงนำออกไปฝาก 16,400 บาท
5. ระบุผู้ถือเงิน ตรวจยอดและยืนยันนำเงินออก ระบบกันยอดนี้ไว้ จากนั้นเปิดรับเงินต่อบน POS หลักได้
6. เมื่อฝากแล้ว เปิดรายการนั้น กรอกยอดฝากจริง วันเวลา และแนบสลิป หากมีเงินกลับมา ให้แยกเป็นเงินเข้าเก๊ะเพิ่มกับเงินกลับเข้ากองรอฝาก ยอดทั้งสามต้องรวมเท่ากับเงินที่นำออก
7. ยืนยันแจ้งฝาก บอทส่งสรุปลงกลุ่ม พร้อมช่วงวันที่ ยอดทุกวัน ยอดฝาก เศษเข้าเก๊ะ และยอดคงเหลือ สถานะเป็น “รอเจ้าของตรวจ”

## เจ้าของร้าน

เปิดรายการจากสรุปในกลุ่ม ตรวจสลิปกับรายการธนาคาร แล้วเลือกยืนยันหรือขอแก้หลักฐาน การยืนยันหรือส่งสรุปซ้ำไม่หักเงินเพิ่ม สลิปต้องเปิดผ่านบัญชีร้าน ไม่ได้ส่งลิงก์สาธารณะลงกลุ่ม

## เมื่อเกิดปัญหา

- เน็ตหลุดหรือไม่แน่ใจว่าบันทึกแล้วหรือยัง: อย่าหยิบหรือย้ายเงินจริงซ้ำ ให้เปิดหน้าเงินสดด้วยบัญชีผู้ทำรายการเดิม แล้วกด “ยืนยันข้อมูลเดิม” ระบบใช้คำขอเดิม
- ยอดบันทึกแล้วแต่ LINE ส่งไม่สำเร็จ: กดส่งเหตุการณ์เดิมซ้ำ ยอดเงินไม่เปลี่ยน
- ยกเลิกการฝาก: คืนเงินที่นำออกทั้งหมดเข้ากองรอฝากและยืนยันคืน ส่วนเศษที่แยกเข้าเก๊ะก่อนออกยังอยู่ในเก๊ะ
- ฝากเพียงบางส่วน: เงินที่ยังไม่ได้ฝากกลับเข้ากองรอฝากของวันเดิม ไม่ถือเป็นเศษเข้าเก๊ะอัตโนมัติ
- ยอดตั้งต้นแสดง “ไม่ทราบวัน”: เป็นเงินค้างก่อนเปิดระบบที่ยังไม่มีหลักฐานแยกวัน ไม่ใช่ยอดขายวันนี้

หน้าฝากเงินและหน้าปิดร้านแสดงเงินเก๊ะ เงินรอฝากในร้าน และเงินที่อยู่กับผู้นำฝากแยกกัน การตั้งวันเตือนและการเปิดส่ง LINE จริงเป็นขั้นตอนตั้งค่าระบบแยกจากคู่มือนี้
