# คู่มือพนักงาน: นำเงินไปฝาก และปิดร้าน

คู่มือสั้นสำหรับสอนพนักงาน (หน้าจอตามเวอร์ชันวันที่ 17 ต.ค. 2026) ใช้กับบัญชีพนักงาน ส่วนเจ้าของร้านมีหน้าตรวจสลิปและแก้ยอดแยกต่างหาก

## รู้จักเงิน 3 อย่างก่อน

| ชื่อบนหน้าจอ | คือเงินอะไร |
| --- | --- |
| **เงินเก๊ะ** | เงินทอนและเงินที่เก็บไว้ใช้ในร้าน หยิบใช้ได้ |
| **เงินรอฝาก** | เงินที่ขายได้ รอเอาไปเข้าธนาคาร (ส่วนที่ยังอยู่ในร้านเรียก "เงินรอฝากในร้าน") |
| **กำลังไปฝาก** | เงินที่หยิบออกจากร้านไปธนาคารแล้ว แต่ยังไม่แจ้งผล |

จำง่ายๆ: เงินขายเข้า **เงินรอฝาก** → หยิบไปธนาคาร กลายเป็น **กำลังไปฝาก** → ฝากเสร็จแจ้งผล เงินที่เหลือกลับร้านจะไปอยู่ที่ **เงินเก๊ะ** หรือกลับเข้า **เงินรอฝาก**

---

## ตอนที่ 1: นำเงินไปฝาก (2 ครั้ง: ก่อนไป และหลังฝาก)

**ไม่ต้องหยุดรับเงินที่ POS** ขายของต่อได้ตามปกติ

### ก่อนไปธนาคาร (ทำก่อนหยิบเงินออกจากร้าน)

1. เปิดหน้า **ฝากเงินร้าน**: พิมพ์ `/ฝากเงิน` ในกลุ่ม LINE แล้วกดปุ่ม หรือเปิดเมนู "เงินสด / นำฝาก" ในแอป
2. กด **"เลือกทุกวัน"** (หรือติ๊กเลือกเฉพาะวันที่จะฝาก) จะเห็นยอดของแต่ละวัน
3. ถ้าจะเก็บเงินส่วนหนึ่งไว้ทอน ใส่ตัวเลขในช่อง **"แยกเข้าเก๊ะ"** แล้ว**หยิบเงินจำนวนนั้นเข้าเก๊ะจริง**ก่อน
4. ดูตัวเลขใหญ่ **"นำออกไปฝาก"** ต้องเท่ากับเงินที่ถืออยู่ในมือจริง
5. ช่อง "ผู้ถือเงินไปฝาก" ใส่ชื่อของคุณให้แล้ว (ถ้าคนอื่นเป็นคนถือไป ให้พิมพ์ชื่อคนนั้นแทน)
6. ติ๊กช่องยืนยัน แล้วกด **"ยืนยันนำเงินออกไปฝาก"** แล้วจึงหยิบเงินออกจากร้าน

### หลังฝากเสร็จ (กลับมาที่หน้าเดิม)

เมื่อกลับมาจะเห็นการ์ดชื่อคุณ สถานะ **"กำลังไปฝาก"**

1. **ฝากธนาคารจริง:** ระบบใส่ยอดที่นำไปให้แล้ว แก้ให้ตรงถ้าฝากไม่ครบ
2. ถ้ามีเงินเหลือกลับร้าน กด **"เงินเหลือกลับร้าน"** แล้วใส่ว่าเข้าเก๊ะเท่าไร คืนเงินรอฝากเท่าไร (ยอดฝาก + เข้าเก๊ะ + คืนเงินรอฝาก ต้องรวมเท่ากับเงินที่นำออกไป)
3. **วันและเวลาที่ฝาก:** ใส่เวลาปัจจุบันให้แล้ว แก้ให้ตรงกับสลิป
4. **แนบรูปสลิป** (รูปถ่ายหรือ PDF)
5. ติ๊กช่องยืนยัน แล้วกด **"ส่งสรุปเข้า LINE"** เจ้าของจะได้รับแจ้งและตรวจสลิป สถานะจะเป็น "แจ้งฝากแล้ว รอเจ้าของตรวจ"

### ถ้าเกิดเหตุไม่ปกติ

- **ไม่ได้ไปฝากแล้ว:** กด "ยกเลิกและคืนเงินทั้งหมด" หลังเอาเงินกลับเข้าร้านจริง พร้อมเขียนเหตุผล
- **เจ้าของขอให้แก้สลิป:** จะเห็นการ์ดขอหลักฐานใหม่ พร้อมข้อความว่าต้องแก้อะไร แนบสลิปใหม่แล้วกดส่งอีกครั้ง
- **เน็ตหลุดตอนกด:** อย่าหยิบหรือย้ายเงินซ้ำ รีเฟรชหน้า ถ้ามีกล่อง "มีรายการที่ต้องตรวจ" ให้กด "ยืนยันข้อมูลเดิม" ระบบจะใช้คำขอเดิม ไม่บันทึกซ้ำ

## ตอนที่ 2: ปิดร้าน (3 ขั้น ทำตามลำดับ)

เปิดเมนู **"ปิดร้าน"** หน้านี้มี 3 ขั้น ขั้นที่ยังทำไม่ได้จะกดไม่ได้และมีข้อความบอกว่าต้องทำอะไรก่อน

### ขั้น ① ให้ POS หยุดรับเงิน

1. ไปที่เครื่อง POS หลัก ส่งบิลที่ค้างให้ครบ แล้วกด **"หยุดรับเงินเพื่อปิดยอด/ส่งมอบ"**
2. กลับมาหน้าปิดร้าน หน้าจะตรวจเองให้ (หรือกด **"ตรวจอีกครั้ง"**) เมื่อพร้อมจะขึ้นเครื่องหมายถูก ✓

### ขั้น ② นับเงินในร้าน

นับเงินจริงในมือ แล้วกรอก 2 ช่อง:

- **เงินเก๊ะที่นับได้จริง**
- **เงินรอฝากที่นับได้ในร้าน** (ไม่รวมเงินที่กำลังไปฝาก)

**พนักงานจะไม่เห็นยอดในระบบ** ให้นับแล้วกรอกตามที่นับได้จริง อย่าเดาและอย่าปัดเลขให้สวย

### ขั้น ③ ตรวจส่วนต่างและยืนยัน

1. กด **"ตรวจยอดและปิดร้าน"** จะมีหน้าต่างบอกผลของแต่ละกอง: **ตรง** / **ขาด ฿...** / **เกิน ฿...**
2. ถ้า **ตรง** กด "บันทึกและส่ง LINE" ได้เลย
3. ถ้า **ไม่ตรง** ต้องเขียน **สาเหตุ** ในช่องที่ขึ้นมา (เช่น "ทอนเกินให้ลูกค้า 20 บาท") ถึงจะกดบันทึกได้ ถ้ารู้ว่านับผิด กด "ยกเลิก" แล้วนับใหม่ได้ ตอนนี้ยังไม่มีอะไรถูกบันทึก
4. กด **"บันทึกและส่ง LINE"** สรุปจะถูกส่งเข้ากลุ่มพร้อมสาเหตุ

> **สำคัญ:** ระบบ**ไม่แก้ยอดให้**เมื่อไม่ตรง แค่บันทึกส่วนต่างและเหตุผลไว้ให้เจ้าของตรวจ และ**ทุกฉบับที่บันทึกจะถูกเก็บไว้และส่งให้เจ้าของเห็น** ถ้าบันทึกไปแล้วพบว่านับผิด บันทึกฉบับใหม่ได้ แต่ฉบับเก่ายังอยู่ ไม่ควรนับซ้ำเพื่อให้ยอดตรง

### หลังปิดร้านเสร็จ

กลับไปที่ POS หลัก กด **"กลับมารับเงิน"** เมื่อจะขายต่อ (ถ้าไม่กด ขายของไม่ได้)

## ปัญหาที่เจอบ่อย

| อาการ | ทำอย่างไร |
| --- | --- |
| กดปุ่มไม่ได้ (ปุ่มจาง) | อ่านบรรทัดเล็กใต้ปุ่ม จะบอกว่าต้องทำอะไรก่อน เช่น ยังไม่ได้เลือกวัน หรือยังกรอกยอดนับไม่ครบ |
| ปิดร้านบอกยอดเปลี่ยนแล้ว | มีรายการเงินเข้ามาระหว่างนับ ให้นับใหม่จากยอดล่าสุด |
| ขั้น ① ไม่ขึ้น ✓ | ยังมีบิลค้างในคิว หรือยังไม่ได้กดหยุดรับเงินที่ POS หลัก |
| ขึ้นว่าส่ง LINE ไม่สำเร็จ | เงินบันทึกแล้ว กด "ส่งแจ้ง LINE อีกครั้ง" หรือ "ส่งสรุปเดิมเข้า LINE" ยอดจะไม่เปลี่ยน |
| เจ้าของถามเรื่องยอดไม่ตรง | ดูสาเหตุที่เขียนไว้ตอนปิดร้านในสรุป LINE |

## จุดที่ต้องจำ 5 ข้อ

1. เงินมี 3 อย่าง: เงินเก๊ะ · เงินรอฝาก · กำลังไปฝาก
2. กด **ยืนยันนำเงินออกไปฝาก ก่อน** หยิบเงินออกจากร้านเสมอ
3. ฝากเสร็จ **กลับมาแจ้งผลพร้อมแนบสลิป** ทุกครั้ง
4. ปิดร้าน: **หยุดรับเงิน → นับเงิน → ตรวจส่วนต่าง** ตามลำดับ
5. ยอดไม่ตรงให้เขียนสาเหตุตามจริง อย่านับซ้ำเพื่อให้ตรง
