# คู่มือเงินสดสองกองและการนำฝาก

สถานะวันที่ 9 ตุลาคม 2026: ติดตั้งฐานข้อมูลใหม่แล้ว แต่ยังไม่ได้ deploy หน้าจอใหม่หรือเปิดยอดตั้งต้น ขั้นตอนด้านล่างใช้หลังผ่านการทดสอบบนระบบจริงและเปิดใช้งานแล้ว

## ยอดที่ต้องดู

หน้า “เงินสดร้าน” (`/cash`) แสดงเงิน 2 กอง และสถานที่ถือเงิน:

| ยอด | ความหมาย |
| --- | --- |
| เงินเก๊ะร้าน | เงินทอนและเงินร้านที่นำมาใช้ต่อได้ รวมเศษที่คืนจากการนำฝาก |
| ยอดขายรอนำฝาก | เงินกองรอฝากทั้งหมด รวมส่วนที่มอบให้ผู้นำฝากแล้วแต่ยังไม่แจ้งจัดการครบ |
| อยู่กับผู้นำฝาก | เงินที่หยิบออกไปฝากและยังอยู่ระหว่างดำเนินการ |
| รอฝากที่ร้าน ใช้ได้ | เงินรอฝากที่ยังอยู่ในร้าน ไม่รวมยอดที่มอบให้ผู้นำฝาก |

ยอด “อยู่กับผู้นำฝาก” เป็นส่วนหนึ่งของยอดรอฝาก ไม่ใช่กองที่ต้องบวกซ้ำ เงินที่เจ้าของยังไม่ตรวจหลักฐานจะแสดงสถานะรอตรวจแยกจากสถานะการถือเงิน

## เปิดใช้งานครั้งแรก

เจ้าของนับเงินจริงแยกเก๊ะกับรอฝากบนเครื่อง POS หลัก ตรวจว่าคิวบิลส่งครบ และหยุดรับ/จ่ายเงินระหว่างนับ ต้องจัดการเงินที่อยู่กับผู้นำฝากเดิมก่อน จากนั้นจึงบันทึกยอดตั้งต้นพร้อมเหตุผลเมื่อระบบได้รับอนุมัติให้เปิดแล้ว ไม่บวกยอดขายย้อนหลังเข้ายอดตั้งต้นซ้ำ

## ใช้งานประจำวัน

- เงินขายสดเข้ากองรอฝาก ส่วนเงินโอนไม่เพิ่มยอดเงินสด
- ปิดการสร้างบิลใหม่แบบ offline ชั่วคราว ต้องเชื่อมต่อระบบก่อนออกบิล บิลค้างเดิมยังเก็บให้ตรวจและส่งซ้ำได้ หากเซิร์ฟเวอร์ยังไม่ยืนยันผล ให้ลองบิลเดิมและอย่ารับเงินซ้ำ นโยบายนี้ยังรอ deploy เช่นเดียวกับหน้าจอใหม่
- เวลาออกค่าใช้จ่ายหรือค่าอะไหล่ เลือกแหล่งเงินให้ตรงกับที่จ่ายจริง: เก๊ะร้าน, เงินรอฝาก หรือเงินโอน รายการโอนไม่หักสองกองเงินสด
- ระบบไม่คำนวณยอดเงินจริงในบัญชีธนาคาร เป็นการระบุแหล่งชำระและติดตามเงินสด

## นำเงินไปฝาก

1. ที่ POS หลัก ส่งคิวบิลให้ครบและกดหยุดรับเงิน ระหว่างหยุด ทุกแท็บงดทำรายการรับ/จ่ายเงิน
2. เปิด “เงินสดร้าน” ตรวจยอดล่าสุด กรอกจำนวนเงินที่หยิบออกและชื่อผู้ถือเงิน กด “ยืนยันนำเงินออกไปฝาก” ก่อนนำเงินออกจากร้าน
3. ระบบแยกยอดที่อยู่กับผู้นำฝากออกจากยอดใช้ได้ในร้าน หลังนำเงินออกให้เปิดรับเงินต่อที่ POS หลักได้ ไม่ต้องหยุดร้านตลอดเวลาที่ไปธนาคาร
4. กลับมาที่รายการนำฝาก กด “แจ้งฝากและแนบสลิป” กรอกยอดฝากธนาคารจริง, เศษที่คืนเข้าเก๊ะ, เงินที่คืนกองรอฝาก และวันเวลาฝาก แนบ JPG/PNG/WebP/PDF ไม่เกิน 10 MiB
5. ยืนยันว่าเงินเศษและเงินคืนกลับเข้าร้านจริงแล้ว ทั้งสามยอดต้องรวมเท่ากับยอดที่นำออกไป ระบบบันทึกและส่งสรุป LINE พร้อมยอดเก๊ะและรอฝากหลังรายการ
6. เจ้าของเปิดหลักฐาน ตรวจรายการธนาคาร แล้วกดยืนยันหรือขอแก้หลักฐาน การกดยืนยันหลักฐานไม่หักเงินซ้ำอีกรอบ

ตัวอย่าง: นำออก 16,457 บาท ฝากธนาคาร 16,400 บาท คืนเข้าเก๊ะ 57 บาท คืนรอฝาก 0 บาท เงินเก๊ะเพิ่ม 57 บาทและหยิบใช้ต่อได้

ถ้านำออก 16,457 บาทแต่ฝากเพียง 10,000 บาท จะเลือกคืนเข้าเก๊ะ 57 บาทและคืนกองรอฝาก 6,400 บาทก็ได้ ต้องนำส่วนที่คืนกลับร้านจริง เงินรอฝากยังติดตามต่อ ไม่ถือทั้งหมดเป็นเศษโดยอัตโนมัติ

ถ้าไม่ได้ฝากเลย ให้ใช้ “ยกเลิกและคืนเงินทั้งหมด” หลังคืนเงินจริงเข้ากองรอฝากแล้ว หากเจ้าของขอแก้หลักฐาน ให้ส่งหลักฐานใหม่ในรายการเดิม

## ปิดร้าน

ส่งคิวบิลครบและหยุดรับเงินที่ POS หลักก่อนนับ ที่ `/close-day` ระบบแสดงเก๊ะ เงินรอฝาก และเงินที่อยู่กับผู้นำฝาก กรอกยอดนับสองกองเฉพาะเงินที่อยู่ในร้าน แล้วตรวจและยืนยันปิดร้าน สรุป LINE แสดงยอดสองกองและส่วนเกิน/ขาด

ยอดนับที่ต่างจากระบบจะถูกบันทึกเป็นส่วนต่าง ไม่ปรับยอดเงินเงียบ ๆ เจ้าของต้องตรวจต้นเหตุและแก้พร้อมเหตุผล หากยอดเปลี่ยนระหว่างนับ ต้องตรวจยอดล่าสุดและนับใหม่

## LINE และการเตือน

LINE รับสรุปการนำเงินออก แจ้งฝาก คืนเงิน ตรวจหลักฐาน และปิดร้าน พร้อมปุ่มเปิดรายการเงินสด การแจ้งและตรวจรายการทำในเว็บที่เปิดจาก LINE รุ่นนี้ไม่ได้อ่านสลิปหรือยืนยันเงินเข้าบัญชีให้อัตโนมัติ

ฝากได้ตามสะดวกทั้งทุกวันและสะสมหลายวัน เจ้าของตั้งวัน เวลาไทย ยอดขั้นต่ำ และเกณฑ์เงินค้างกับผู้นำฝากได้ เช่น ศุกร์ 10:00 การเตือนจะทำงานหลังตั้ง CRON_SECRET, deploy และเปิด scheduler/config ภายใต้การอนุมัติแยก ตอนนี้ยังปิดอยู่

ถ้าบันทึกเงินสำเร็จแต่ส่ง LINE ไม่สำเร็จ ให้กดส่งสรุปเดิมซ้ำ ไม่สร้างรายการเงินใหม่ หากยังไม่ทราบผลการบันทึก ให้ลองยืนยันรายการเดิมด้วยข้อมูลเดิมก่อนทำรายการใหม่

## สิ่งที่ยังต้องทำก่อนใช้จริง

Deploy หน้าจอและผู้เขียนรายการเงินที่เข้ากันได้ ทดสอบด้วยบัญชีจริงรวมหลักฐานส่วนตัว อนุมัติเปิดระบบและให้เจ้าของนับยอดตั้งต้น แล้วจึงทดสอบส่ง LINE จริงและเปิดการเตือนตามวันเวลาที่เลือก ดู [แผนขึ้นจริง](plan-production-two-fund-cash-2026-10-09.md) และ [ขั้นตอน cutover](cutover-two-fund-cash.md)
