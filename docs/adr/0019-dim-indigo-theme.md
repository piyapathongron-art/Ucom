# 0019 — โทนสีใหม่: dim indigo theme แทนโทนสว่าง+ทอง-น้ำตาลเดิม

## สถานะ

Accepted, 2026-08-16 — **supersede ส่วน "สว่างเป็นฐาน" ของ
[[0015-receipt-direction-and-desktop-first-responsive]] และค่าสี accent ทั้งหมดของ
[[0018-uxui-redesign-v2-direction]]** (หลักการ density-first/receipt-direction ของ 0015 ยังอยู่
เปลี่ยนแค่ว่าพื้นฐานเป็นสว่างหรือมืด)

## บริบท (ลำดับการเคาะ — เก็บไว้เพราะแต่ละก้าวมีเหตุผลของมัน)

1. เจ้าของร้านเห็นปุ่ม "ปิดบิล" (`/pos`) เป็นทอง-น้ำตาลจาง (ที่จริงคือ disabled state 40% opacity)
   รู้สึกว่าไม่กลมกลืนกับพื้น neutral ขาว-เทาเดิม → เปลี่ยน accent เป็นครามเข้ม `#3730A3`
2. ขยายโจทย์เป็นทั้งเว็บแอป "โทนคราม สงบ tech luxury มี gradient ได้" → เสนอ 2 ทาง (ยับยั้งชั่งใจ
   vs รื้อเต็ม) เจ้าของร้านเลือกยับยั้งชั่งใจ: neutrals ออกครามอ่อน + gradient เฉพาะปุ่ม/nav/login
3. ทดสอบแล้วบอกว่า bg ยังขาวเกินไป ปรับให้ครามชัดขึ้น (`#EEEDFA`) ยังไม่พอ
4. เคาะสุดท้าย: **"งั้น redesign อีกที อยากให้เป็นเชิง dark mode แต่ไม่มืดจนเกินไป"** — นี่คือทิศทาง
   ที่ใช้จริงในเอกสารนี้

## การตัดสินใจ

พื้นฐานทั้งระบบเปลี่ยนจากสว่างเป็น **dim** (มืดพอสมควรแต่ไม่ดำสนิท) โทนคราม-น้ำเงินเข้ม ไม่ใช่เทา/ดำ
ล้วนแบบ dark mode ทั่วไป

### Neutrals

| Token | ค่า | บทบาท |
|---|---|---|
| `--color-background` | `#14132B` | พื้นหน้าเว็บ — indigo-navy เข้ม ไม่ใช่ดำสนิท |
| `--color-surface` | `#1D1C3E` | การ์ด/ตาราง/input — สว่างกว่า background เล็กน้อยให้ดูลอยเป็นชั้น |
| `--color-border` | `#34315F` | เส้นแบ่ง — ครามเข้มแต่มองเห็นชัดบนพื้นมืด |
| `--color-ink` | `#F3F2FB` | ตัวหนังสือหลัก — ขาวอมม่วงอ่อน (ไม่ใช้ `#FFFFFF` จัดเพื่อลด eye strain) |
| `--color-ink-muted` | `#A6A3CE` | ตัวหนังสือรอง — ลาเวนเดอร์เทา ผ่าน contrast 6.8:1 บน background |

`--color-surface` ยังคงใช้กับตาราง/การ์ดสินค้าทุกที่เหมือนเดิม (ไม่ใช่ gradient) — ยังยึด
density-first ของ 0015: ข้อมูลต้องอ่านไวที่หน้าร้าน gradient ยังจำกัดไว้แค่ 3 จุดเดิม (ดูหัวข้อ
gradient ด้านล่าง)

### สถานะ (warning/danger/success) — ต้องปรับให้สว่างขึ้นเพราะพื้นเปลี่ยนขั้ว

ค่าเดิมเป็นโทนเข้ม (ทำมาให้ใช้บนพื้นสว่าง) พอพื้นกลับเป็นมืด ตัวหนังสือ/border สีเข้มจะอ่านไม่ออก
ต้องสลับเป็นเวอร์ชันสว่างของ hue เดิม (ยังคง "ส้ม=เตือน, แดง=อันตราย, เขียว=สำเร็จ" identity เดิม):

| Token | เดิม (พื้นสว่าง) | ใหม่ (พื้นมืด) |
|---|---|---|
| `--color-warning` | `#A85B00` | `#F59E0B` |
| `--color-danger` | `#B42318` | `#F87171` |
| `--color-success` | `#05704A` | `#34D399` |

### Accent — แยกเป็น 2 บทบาทเพราะพื้นมืดทำให้ "สีเดียวใช้ได้ทุกที่" ไม่จริงอีกต่อไป

บนพื้นสว่าง accent ตัวเดียวใช้ได้ทั้งเป็นพื้นปุ่ม (ตัวหนังสือขาวทับ) และเป็นสีตัวหนังสือ/border บน
badge ได้พร้อมกัน แต่บนพื้นมืด สองบทบาทนี้ต้องการความสว่างคนละขั้ว — พื้นปุ่มต้อง**เข้ม**พอให้
ตัวหนังสือขาวอ่านออก (contrast ≥ 4.5:1) ส่วนตัวหนังสือ/border บนพื้นมืดต้อง**สว่าง**พอให้อ่านออก
จากพื้นมืดเอง เลยแยก token:

| Token | ค่า | ใช้ที่ไหน |
|---|---|---|
| `--color-accent` | `#818CF8` (indigo-400 สว่าง) | ตัวหนังสือ/border บนพื้นมืด: nav active tab, badge `bg-accent/10 text-accent`, focus outline ของ `.ucom-primary` |
| `--color-accent-strong` | `#4338CA` (indigo-700 เข้ม) | stop แรกของ gradient พื้นปุ่ม `.ucom-primary`/`.ucom-badge-glow` — ตัวหนังสือขาวทับได้คอนทราสต์ 7.9:1 |
| `--color-accent-soft` | `#4F46E5` (indigo-600 กลาง) | stop ที่สองของ gradient เดียวกัน — คอนทราสต์ตัวหนังสือขาว 6.3:1 |

ทุกค่าเช็คคอนทราสต์ผ่าน WCAG AA (4.5:1 ขึ้นไปสำหรับตัวหนังสือปกติ) แล้วก่อนเลือก

### Gradient — ยังจำกัดขอบเขตเท่าเดิม (3 จุด)

ไม่เปลี่ยนจากรอบก่อน — พื้นตาราง/การ์ดสินค้ายังแบนราบ:
1. `.ucom-primary` (ปุ่ม CTA หลักทุกหน้า)
2. Nav header (`.ucom-header-wash`) — wash บางๆ ระหว่าง surface กับ background (ตอนนี้ทั้งคู่มืด
   ผลคือมิติเข้มขึ้นเล็กน้อย ไม่ใช่ความสว่าง)
3. `/login` (`.ucom-login-glow` เป็น radial glow ของ accent สว่างบนพื้นมืด — จุดนี้เด่นขึ้นกว่ารอบ
   พื้นสว่างเพราะ glow ตัดกับพื้นมืดชัดกว่า, `.ucom-badge-glow` โลโก้ "U")

## ผลกระทบต่อโค้ด

`globals.css`: token ทั้งชุดด้านบน + `.ucom-primary`/`.ucom-badge-glow` เปลี่ยนไปใช้
`--color-accent-strong` → `--color-accent-soft` แทน `--color-accent` → `--color-accent-soft` เดิม
(กัน contrast พัง เพราะ `--color-accent` ตอนนี้เป็นตัวสว่างแล้ว ใช้เป็นพื้นปุ่มไม่ได้อีกต่อไป)

โค้ดอื่นไม่ต้องแก้ — ทุกหน้าอ้างอิง token กลาง (`bg-surface`, `text-ink`, `bg-ink text-surface` สำหรับ
toggle ที่เลือกอยู่ ฯลฯ) พอ token กลับขั้วเป็นมืด ทุกอย่างพลิกสีถูกต้องอัตโนมัติ — ที่ตรวจแล้วว่ายัง
ถูกต้องหลังพลิกขั้ว: ปุ่ม toggle ที่เลือกอยู่ (`bg-ink text-surface` ใน `Cart.tsx`/`Catalog.tsx`
กลายเป็น chip สว่างบนพื้นมืด ยังอ่านง่าย), badge สถานะทุกแบบ (`bg-{color}/10 text-{color}` ยัง
คอนทราสต์ผ่านเพราะพื้น chip เป็นแค่ 10% opacity ทับพื้นมืดอยู่ดี)
