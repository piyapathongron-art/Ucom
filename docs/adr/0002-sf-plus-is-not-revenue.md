# 0002 — เครื่อง SF+ ที่ลูกค้าผ่อน ไม่นับเป็นยอดขาย

- **สถานะ:** ตัดสินใจแล้ว
- **วันที่:** 2026-08-05

## บริบท

SF ส่งเครื่องมาให้ร้านโดยตัดจากวงเงินเครดิต ร้านไม่จ่ายเงินตอนรับเครื่อง แต่ละบิลที่สั่งมีกำหนดชำระร่วมกัน ~2 สัปดาห์

- **มีลูกค้ามาผ่อนทัน** — ลูกค้าทำสัญญากับ **SF ไม่ใช่กับร้าน** ร้านไม่เก็บค่างวด ไม่รับความเสี่ยงลูกค้าเบี้ยว ร้านได้เครดิตคืนเต็มจำนวน + ค่าคอมต่อเครื่อง **เงินค่าเครื่องไม่เคยผ่านมือร้านเลย**
- **ไม่มีใครผ่อนจนเลยกำหนด** — ร้านจ่ายเต็มราคาป้าย เครื่องกลายเป็นของร้าน
- **จ่ายเต็มไปแล้วค่อยมีคนผ่อน** — ได้เครดิตเติมกลับ + ค่าคอม

ในระบบเดิม เงินก้อนนี้ถูกจดเป็นแถวใน `expenseList` ชื่อ `"SF+"` 21 แถว — ยอดตรงกับ **ราคาป้ายของโทรศัพท์แบบเป๊ะ 21/21 แถว** และไม่ตรงกับต้นทุนสักแถวเดียว รวมกับรายการไฟแนนซ์อื่น (`ไทยช่วยไทย`, `อิออน`, `ผ่อน jmart`) เป็น 295,463 บาท = **93% ของยอดที่อยู่ในรายการ "รายจ่าย"** แปลว่าตารางรายจ่ายของระบบเดิมแทบไม่ได้บันทึกรายจ่ายจริงเลย

## ทางเลือกที่ชั่ง

1. **ออกบิลขายเต็มราคา 13,999 แล้วลงต้นทุน 13,999** ให้กำไรเป็น 0 แล้วบวกค่าคอมทีหลัง — ยอดขายรายเดือนจะดูใหญ่ แต่เป็นตัวเลขที่ไม่มีเงินรองรับ
2. **ออกบิลเฉพาะส่วนที่ลูกค้าจ่ายร้านจริง** — ตกไปเพราะเจ้าของร้านยืนยันว่าลูกค้าไม่จ่ายเงินให้ร้านเลย (อย่างมากซื้อฟิล์มแยกบิล)
3. **ไม่ออกบิลขาย บันทึกค่าคอมเป็นรายได้ก้อนแยก** ← เลือกอันนี้

## การตัดสินใจ

ตั้งกฎกลางของทั้งระบบ: **ยอดขาย = เงินที่เข้าร้านจริง**

เครื่อง SF+ ที่ปล่อยผ่อนสำเร็จจึงไม่สร้างบิลขาย แค่เปลี่ยนสถานะเครื่องและบันทึกค่าคอม ค่าคอมเป็น**จำนวนกรอกมือต่อเครื่อง** ไม่ใช่สูตร (แล้วแต่รุ่น)

รายงานแยก 3 ท่อ: ขายสด / งานซ่อม / ค่าคอม SF+ โดยท่อที่สามโชว์**จำนวนเครื่อง**แทนยอดขาย

กำหนดชำระผูกกับ **`sf_orders` (บิลที่สั่ง)** ไม่ใช่ผูกกับเครื่องรายตัวและไม่ใช่รอบปฏิทิน การแจ้งเตือนจึงเตือนเป็นรายบิล — "บิล #7 ครบกำหนด 12 ส.ค. ยังไม่มีคนผ่อน 4 เครื่อง รวม 45,996"

## ผลที่ยอมรับ

- ตัวเลข "ยอดขาย" ของระบบใหม่จะต่ำกว่าระบบเดิมมากในเดือนที่มีเครื่อง SF+ เยอะ — ตั้งใจให้เป็นแบบนั้น
- **ต้องมีทางออกสองปุ่มในหน้าเลือกเครื่อง** (ผ่อน SF / ขายสด) เพราะเครื่องที่เลยกำหนดจ่ายเต็มแล้วกลายเป็นเครื่องของร้านที่ขายสดได้ปกติ
- ประวัติ SF+ 21 แถวเดิม**ประกอบกลับไม่ได้** มีแค่ชื่อ+ยอด+วันที่ ไม่มี IMEI ไม่มีบิลสั่ง
